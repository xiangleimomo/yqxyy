# 词汇街机（本地版）

这是独立的静态 HTML5 小游戏库，无需安装依赖或联网。当前修订以经典玩法的规则和操作为基础，使用自行绘制的界面。

## 视觉升级版

- 大厅改为复古街机主题：原创街机插画、27 张真实游戏画面封面、分类筛选、名称搜索和词库 / 成绩概况。
- 各游戏使用独立场景配色：矿洞、海洋、星空、木质运动场、花园迷宫、工业平台等。
- 加入角色、飞船、坦克、鱼、水果、毛绒玩具等原创绘制造型，以及金块切面、球体高光、木箱纹理、按钮压感和立体卡牌。
- 得分与消失对象触发粒子反馈，受击增加边缘提示；表现层独立于游戏的碰撞、移动和计分逻辑。
- 填字、找词、翻牌和接接乐也更新了画面。布局适配手机，提供可见的键盘焦点，界面动画响应减少动态效果设置。

所有资源均保存在本文件夹，离线仍可使用。发布时必须一并上传 `polish.css`、`visuals.js`、`lobby.js` 和 `assets/previews/`。封面采用示例词库的截图，不随自定义词库重新生成。

视觉升级后已重跑原有玩法检查，并另外检查了 27 张封面加载、分类 / 搜索 / 进入游戏、返回顶部、手机布局、暂停和粒子渲染。

## 打开方式

直接双击 `index.html`，或把整个 `english-arcade` 文件夹部署到 GitHub Pages 等静态网站服务。

## 与原作的对应范围

本版实现上述经典玩法的主要操作和胜负规则，使用原创绘制的简洁图形与自建 / 随机关卡，未复制商业游戏的原贴图、音效或完整原版关卡。动作和平台类的敌人行为、物理细节及奖励种类仍比商业原作精简。G20 保持原计划中的“简化版”，使用当前词库组盘，不包含原版每日主题题库。运动类保留本身的计分规则，英语词汇以球瓶、关卡提示或附加目标呈现。

淘金者的无跳跃、脚旁挖坑、回填和守卫陷阱设计参考 [Tozai 官方玩法说明](https://global.tozaigames.com/loderunner/gameinfo/tips)。其他游戏按本 README 的具体规则实现，不承诺复刻某一发行版本的全部细节。

## 词库格式

在网页的“词库”页中，每行填写一组 `英文,中文`。至少 4 个不同的单词，每词 2–16 个英文字母，例如：

```text
apple,苹果
bridge,桥
```

词库与成绩都保存在当前浏览器；清理浏览器网站数据会将它们清除。

填字游戏每盘选取能够拼入同一交叉网格的词，并显示未能放入的词数；不保证所有词同时入盘。当前属于自由布局的词汇交叉填字，不采用美式报纸填字的每格双向检查及旋转对称约束。

## 版本与验证

单词显示修正版：泡泡龙、保龄球、太空入侵者、坦克、炸弹人与拆墙游戏不再截取单词前几个字母。泡泡龙的待发球、下一颗和飞行球均显示完整拼写。15 款带词汇物件的游戏增加完整词汇对照，指向或触碰物件可在场地下方放大阅读。长单词在小物件内按宽度压缩，不删字母；正常字号的完整拼写和中文含义保留在对照区。抓娃娃标签限制宽度，避免长词标签互相覆盖。填字、找词、迷阵和字母收集中的单字母及拼词进度属于玩法，不改为整词物件。

新增检查覆盖 15 款词汇物件游戏的默认词库及 15–16 字母长词、泡泡当前/下一颗/飞行球、指向放大，以及 390px 手机布局；并重跑启动和关键玩法回归检查。

## 发布到 GitHub Pages

将此文件夹中的全部文件（含所有 `.js` 与 `style.css`）放入仓库发布目录，保留 `index.html` 在该目录顶层。全部采用相对路径，不需要安装依赖或打包构建。GitHub Pages 选择该目录对应的分支即可。页面没有后台服务，不上传词库或成绩。
