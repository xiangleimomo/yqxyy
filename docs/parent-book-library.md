# 家长绘本功能

绘本阅读导航保留我的收藏、最近阅读。右下角“＋”进入上传；账号管理的“管理我的绘本”进入自己的上传管理。游客点击个人功能会进入登录提示。

搜索统一使用顶部搜索框，按当前绘本、动画故事或光影课堂板块限定结果。绘本搜索包含全集绘本库和公开上传的绘本，可按书名、上传者检索，不混入动画系列结果。上传前查重仍检查配套动画。

我的收藏按自定义分类折叠展示，未分类的收藏单列；一次只展开一个书架。最近阅读仅显示时间最新的五本可用绘本。两页使用封面、居中书名和悬浮阅读操作，不显示申请列表或额外阅读详情。申请管理继续放在账号管理的“管理我的绘本”。

注册时填写账号昵称、邮箱和密码。已有账号在账号管理中设置或修改昵称，上传使用同一昵称，已上传书籍的公开昵称随账号昵称同步更新。登录后显示昵称。已标记为孩子的家庭账号无法上传；原有账号继续有效，新账号须完成邮箱确认。昵称是公开显示信息，不用于判断管理员权限。

上传前可按书名检索站内绘本和配套动画。上传文件或发布资料时再次检索，存在相关资源时必须二次确认。PDF 可配套上传音频、视频，也可填写直链；PDF 封面自动提取，可自行另选封面。

封面悬浮操作中的“收藏 / 分类”保存个人收藏及分类，支持鼠标、键盘聚焦，触屏点击封面展开。“我的收藏”支持按分类筛选。使用“本站阅览器”阅读时，页码按账号保存；“最近阅读”的“继续阅读”会恢复位置。外部直链阅读器无法向本站回传翻页位置。本地文件的进度保留在本设备。

家长发布后没有直接修改、删除权限。“我的上传”提供申请修改、申请删除入口，提交审核期间保留当前版本。管理员在“管理绘本”底部审核，通过后修改或删除生效。管理员原有编辑、删除、排序权限保留。

数据库写入经 book_portal RPC 校验当前用户、所有权及可信管理员声明；个人记录和审核申请受 RLS 保护。文件沿用时光馆的 Supabase Edge Function 流式转发方式调用 Pone API，不经过 Netlify，不写入服务器磁盘或 Supabase Storage。绘本、音频、视频和新封面文件存于 Pone，数据库保存直链与书籍信息。中转先验证登录身份及家长权限，不向 Pone 转发登录凭据。单文件最大 1 GiB，转发超时 130 秒，前端等待 140 秒。

验证：`node scripts/test-book-admin.cjs`、`node scripts/test-parent-books-ui.cjs`（需 Playwright、Edge、本地 8127 静态服务）；数据库 `scripts/test-parent-books.sql` 使用临时测试账号、在事务中测试并回滚，不保留测试数据。
