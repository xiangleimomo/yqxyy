# 家长绘本功能

绘本阅读导航：上传绘本、我的上传、我的收藏、最近阅读。游客点击个人功能会进入登录提示。

家长首次上传时设置公开昵称并确认家长身份。已标记为孩子的家庭账号无法开通上传；原有账号继续有效，新账号须完成邮箱确认。昵称与发布书籍绑定，公开页面不显示邮箱。

上传前可按书名检索站内绘本和配套动画。上传文件或发布资料时再次检索，存在相关资源时必须二次确认。PDF 可配套上传音频、视频，也可填写直链；PDF 封面自动提取，可自行另选封面。

书籍卡片的“收藏 / 分类”保存个人收藏及分类。“我的收藏”支持按分类筛选。使用“本站阅览器”阅读时，页码按账号保存；“最近阅读”的“继续阅读”会恢复位置。外部直链阅读器无法向本站回传翻页位置。本地文件的进度保留在本设备。

家长发布后没有直接修改、删除权限。“我的上传”提供申请修改、申请删除入口，提交审核期间保留当前版本。管理员在“管理绘本”底部审核，通过后修改或删除生效。管理员原有编辑、删除、排序权限保留。

数据库写入经 book_portal RPC 校验当前用户、所有权及可信管理员声明；个人记录和审核申请受 RLS 保护。上传中转先验证登录身份，再核验家长上传权限，不向 Pone 转发登录凭据。

验证：`node scripts/test-book-admin.cjs`、`node scripts/test-parent-books-ui.cjs`（需 Playwright、Edge、本地 8127 静态服务）；数据库 `scripts/test-parent-books.sql` 使用临时测试账号、在事务中测试并回滚，不保留测试数据。
