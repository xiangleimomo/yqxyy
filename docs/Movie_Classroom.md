# 光影课堂 · Watch 第一版

入口：`#/movies`；单部影片：`#/movie/<id>`。

## 电影目录与待上线管理

`data/movie-series.json` 是电影系列索引：保存中文名、英语名、建议难度与推荐度。每个系列的影片清单已拆到独立文件夹，例如 `data/movies/harry-potter/movies.json` 保存哈利·波特八部；新增、删除或排序影片只修改对应文件夹。电影首页按系列展示，并可依英语难度筛选；进入系列后会读取并显示该系列的全部影片。

每部影片的完整 `sources` 配置已经预先生成。只有当所属 `data/movies/<系列ID>/movies.json` 的 `sources` 中同一个 `id` 的 `hlsUrl` 不为空时，页面才显示 **Watch**；空地址会统一显示 **待上线**，不会尝试加载第三方视频地址。

新增可播放影片时，只需：

1. 在 `data/movies/<系列ID>/movies.json` 中新增影片的 `id`、英文名、中文名与年份；
2. 在同一文件的 `sources` 数组中，找到相同 `id` 的对象，只填写 `hlsUrl` 的空字符串内容；其他字段不要删除；
3. 可选填写 `cover`，优先使用片方公开且稳定的海报地址；不要使用会防盗链的图片外链。

- 第一版仅提供电影目录、搜索、题材筛选和 Watch 播放，不包含听读、单词、测验或配音。
- 影片资料单独存放在 `data/movies.json`，不修改动画故事的课程或解锁规则。
- 添加影片时填写唯一的 `id`、中英文名称、年份、题材、合集、海报和 `hlsUrl`。
- 哈利·波特八部影片均使用 NCAT 页面中名称恰为“蓝光”的线路，不混用“蓝光1/3/7”等其他线路。`sourcePage` 保存对应播放页供后续核对，`seriesOrder` 为系列顺序。
- 2026-10-03 更新：通过正常浏览器逐部选择“蓝光”并观察实际 HLS 请求，补齐密室、火焰杯、混血王子、死亡圣器上/下。现有三部的最新地址与仓库已有更新一致，保留原更新。
- 当前地址未包含原先的 `sign`/`timestamp` 参数，但这不代表永久有效。本版不自动跟随源站更换地址。
- 更新片源：修改对应的 `hlsUrl` 后发布；播放器里的“重新加载”只重试当前配置，并非自动解析或获取新地址。
- 海报取自 https://www.harrypotter.com/discover/films 对应的公开影片展示素材，当前使用外部图片地址。
- 视频加载失败会显示提示，不自动跳转到第三方页面。离开电影页面时释放播放器连接。
- 可运行 `node scripts/inspect-harry-potter-sources.cjs` 核对线路，或在命令末尾传入具体影片 ID。需安装 Playwright 和 Chrome；脚本只输出结果，不直接修改目录，缺少目标线路或页面跳转时会报告失败，不自动使用其他线路。

验证：`node --check js/app.js`、`node --check js/movies.js`、`git diff --check`，并检查桌面/手机目录、搜索、播放、重试及返回动画故事。
