# 光影课堂 · Watch 第一版

入口：`#/movies`；单部影片：`#/movie/<id>`。

- 第一版仅提供电影目录、搜索、题材筛选和 Watch 播放，不包含听读、单词、测验或配音。
- 影片资料单独存放在 `data/movies.json`，不修改动画故事的课程或解锁规则。
- 添加影片时填写唯一的 `id`、中英文名称、年份、题材、合集、海报和 `hlsUrl`。
- 当前三条 HLS 地址由网站所有者提供并指定用于这一版。它们含源站签名，可能失效；本版不根据 `timestamp` 推断有效期，也不自动刷新签名。
- 更新片源：修改对应的 `hlsUrl` 后发布；播放器里的“重新加载”只重试当前配置，并非自动解析或获取新地址。
- 海报取自 https://www.harrypotter.com/discover/films 对应的公开影片展示素材，当前使用外部图片地址。
- 视频加载失败会显示提示，不自动跳转到第三方页面。离开电影页面时释放播放器连接。

验证：`node --check js/app.js`、`node --check js/movies.js`、`git diff --check`，并检查桌面/手机目录、搜索、播放、重试及返回动画故事。
