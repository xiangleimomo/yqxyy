# 动画与电影书架

动画故事、光影课堂使用与绘本一致的封面和居中标题书架。封面悬浮操作提供进入内容及“收藏 / 分类”，触屏点击封面展开，键盘聚焦同样可使用。动画保留 Level 筛选及按等级分组，游客筛选、课程解锁和测验规则保持有效。光影课堂保留难度筛选、多平台播放入口及单部影片列表。

每个板块有“我的收藏”和“观看记录”。收藏按自定义分类折叠，一次展开一个类别。动画按系列收藏，电影支持收藏系列和单部影片；两种媒体分别展示收藏和历史。观看记录每区显示最近五项，动画保留该系列最近观看的一集，电影保留单部影片；电影分集学习与整部观看归于同一影片记录，“继续观看”进入对应的上次入口。

复用已受 RLS 保护的 book_personal 个人收藏/历史存储及 book_portal RPC。命名空间 anim-、film-、film-series- 区分静态目录中的动画、单部电影和系列，不修改绘本记录。favorite/category 是收藏分类；last_cfi 存放观看入口、集数和秒数的 JSON 元数据；last_read_at 用于排序。昵称、授权、书籍发布及审核权限均不受影响。

原有学习进度中 modules.watch 的记录可作为旧动画观看历史补充。新观看记录不会被后续测验时间替代。原生 VIDEO 播放时及每五秒保存进度，暂停和销毁时再次保存；使用当前账号的本地缓存及云端记录恢复位置。外部跨域 iframe 只能记录播放器入口加载，无法读取其内部播放秒数；不改变播放器来源。AUDIO 不注册视频历史监听，不添加视频画面。

检查：node scripts/test-media-shelves-ui.cjs、node scripts/test-hls-playback.cjs。前者需要 Playwright、Edge 和本地 8127 静态服务，验证分级、封面收藏、分类书架、两区最近五项、秒数恢复、账号隔离及音频边界。
