# 电影默认播放器

光影课堂沿用本站 `#/movie/<id>` 播放页，默认在原播放器位置嵌入 `https://dulo.mov/watch/movie/<TMDB编号>`。82 部影片的编号来自现有 `data/movie-hub-catalog.json`，不使用旧目录里已经失效的固定主片源 URL，也不跳转浏览器到 Dulo 网站。Dulo 播放器自行加载它的最新播放线路。

播放模式由 `data/movie-playback.json` 控制：

```json
{
  "mode": "dulo",
  "legacyPrimaryEnabled": false
}
```

原 `data/movies/*/movies.json` 中的 `hlsUrl`、原嵌入地址、备用片源、学习课程等数据均保留。Dulo 模式不显示和启用旧主片源 / 备用源选择器。以后需要恢复本站原播放器时，改为 `"mode": "legacy"`、`"legacyPrimaryEnabled": true` 后部署即可；是否能播放仍取决于恢复时相应地址的有效性。

Dulo 框架允许脚本、同源运行、表单和演示，保留沙箱隔离；允许播放器全屏、音视频及画中画，禁止子页面主动跳转本站顶层。浏览器地址及站内导航保持不变。播放页保留原有“其他播放平台”和课程学习入口。

电影页面不再生成作品徽章、进度提示框或答题按钮。电影主线答题从“我的荣誉馆 → 作品徽章馆 → 电影主线 → 对应徽章”进入，徽章进度继续在该处显示。

基本核对包括：82 个有效电影编号、默认模式下的 Dulo 嵌入地址、旧模式恢复开关、JavaScript 语法和 diff。未创建临时账号；没有把页面加载成功当作所有影片已确认播放。

## 实时直链播放

电影页新增“本站直链播放”选项。点击时，`/.netlify/functions/movie-stream?id=<本站电影编号>` 只接收本站目录中的电影编号；根据 Dulo 的公开运行配置查询对应 TMDB 影片的临时 HLS 地址，再交给本站播放器播放。临时链接和观看转交参数只在这次请求与页面内存中使用，服务端响应禁止缓存，不写入目录、不记录到日志。重新加载会重新解析，避免再次固定失效链接。

解析脚本：`node scripts/extract-dulo-stream.cjs harry-potter-philosophers-stone`。输出包含临时链接，不要提交其输出文件。解析模块为 `netlify/lib/dulo-stream.cjs`，固定访问 Dulo 的公开配置及其指定的 zcdn Workers 域名，不接受用户指定上游 URL。未登录也可使用原有电影播放权限，不增加测试账号。

HLS.js 使用本站托管的固定版本 1.5.20，避免播放器组件本身还依赖访问外部 CDN。HLS 子播放列表和分片只在同一影片路径及同源请求中携带必要的临时观看参数。原 Dulo 播放器可随时切回；旧主片源继续停用。

该功能只解析地址，不转发实际视频流、不产生整部电影的服务器中转流量。直链仍由浏览器访问 Dulo 视频域名；如果该域名在用户网络下不可达，解析成功仍可能无法播放，需要可直连来源或视频中转，不能将“拿到直链”视为已解决网络可达性。

兼容性补充：视频服务对本站 Origin 的播放列表响应未返回 Access-Control-Allow-Origin，因此优先使用浏览器原生 HLS（无需 JavaScript 跨域读取播放列表）。不支持原生 HLS 的浏览器，仍可能需要上游开放跨域或视频中转；解析地址本身不能解除跨域限制。
