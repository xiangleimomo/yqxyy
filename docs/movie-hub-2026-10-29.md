# Optional movie aggregation page

Entry: `#/movie-hub`. The original catalogue and primary/backup URLs are unchanged.
Each original Watch page links to the same film in the hub. The hub offers title,
year and series filtering and manual provider selection.

82 existing films were matched by normalized English title plus exact release year
against StreamJuju's public search metadata. Narnia's full titles and the alternate
Harry Potter title are explicit aliases in `scripts/build-movie-hub-catalog.cjs`.
Ambiguous or unmatched results receive no generated player URL. To refresh only
this separate catalogue, run `node scripts/build-movie-hub-catalog.cjs --apply`.
No media URLs, credentials, cookies or upstream player code are imported.

Provider contracts checked:

- VidSrc: <https://vidsrc.sh/vidsrc/docs/>, `/embed/movie/{tmdbId}`.
- VidLink: <https://vidlink.pro/>, `/movie/{tmdbId}`.
- 111Movies: <https://111movies.net/movie/109445> currently redirects to
  `player.vidlove.st`; kept as a new-tab entry after unsuccessful playback tests.
- StreamJuju: <https://streamjuju.cyou/watch/movie/109445>, new-tab entry.

The two embedded providers explicitly reject sandboxed frames. The optional hub
uses their standard cross-origin iframe contract only after the viewer clicks a
provider. The original player's iframe sandbox is unchanged. Switching, closing
or leaving the page removes the previous frame and its message listener/timer.
New-tab links use `noopener noreferrer`.

An iframe load is reported only as a loaded page, never successful playback.
Playback status requires a `PLAYER_EVENT` from the selected frame and exact
provider origin, with positive duration, nonnegative finite time, and a matching
TMDB ID when supplied. Status is not persisted as a general availability claim.
