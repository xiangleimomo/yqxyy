# 动画工具与跨阅读区收藏

顶部移除学习记录、独立书架、单词表、英文写作四个入口。动画故事页签内保留全部动画、我的收藏、观看记录，并增加单词表和英文写作。旧学习记录链接转到动画观看记录，旧书架链接转到动画我的收藏。

动画“我的收藏”的系列卡片显示已学集数和进度条，悬停可继续学习；进度来自原有账号学习记录，不增加新的学习进度体系。

单词表和英文写作共用已有账号收藏，支持关键词搜索、来源筛选、自定义分类、朗读、移除及返回来源。动画阅读原有收藏继续保留；绘本和期刊的新收藏额外保存书名、来源类型和页码。移除操作保留删除时间用于跨设备同步，避免旧设备的收藏重新出现；重新收藏可恢复。

PDF 本站阅读器新增工具按钮“Aa · 文字 / 划词收藏”。打开后读取当前页文字，可切换文字页码；选中英文单词或句子后使用划词弹窗收藏。只按需提取所选页面，不等待整本书的文字索引。PDF 仅图片页面显示无文字提示，本次不接入 OCR。

EPUB 使用阅读器内已有文字，支持直接选词或划选句子。顶部 Aa 按钮可开启划词收藏。词典弹窗支持全屏阅读，收藏统一进入动画故事内的单词表 / 英文写作。直接在浏览器打开外部 PDF 时使用的是浏览器阅读器，需要选择本站阅读器才能使用本功能。

本次不创建临时账号，不修改账户权限和数据库结构。基本检查包括相关 JavaScript 语法、diff、收藏同步合并及动画导航/进度生成。
