# 管理员更新绘本

1. 使用现有管理员账号登录网站。
2. 打开“绘本阅读 → 管理绘本”（`#/reading/admin`）。
3. 选择“新增绘本”，或从下拉框选择需要更新的绘本。
4. 选择 PDF，等待自动读取首页封面，再点击“上传至 Pone”；上传成功后直链会自动填入。已有 `https://u.pone.rs/…pdf` 地址也可以直接填写。
5. 填写名称、分级和简介；需要时另选一张封面图片。
6. 核对右侧预览，点击“确认发布”。其他访客刷新书架后即可看到，不必提交代码或重新部署。

PDF 经本站上传通道转发到 [Pone 官方上传接口](https://pone.rs/api)，单文件上限 1 GiB。上传失败不会自动发布，管理员可重试或填写已有直链。

绘本信息保存在 Supabase `public.story_books` 表。数据库启用 RLS，所有访客可读取，只有签名令牌的 `app_metadata.site_admin` 为 `true` 的账号可以新增和更新。上传服务还会调用 Supabase Auth 再次确认当前管理员身份。管理员登录令牌不会转发给 Pone；浏览器和代码中不需要服务端密钥。

现有静态目录 `data/books.json` 作为基础书架。云端同 ID 的记录优先显示，未覆盖的静态绘本继续保留。本站阅览器的下载通道也读取云端直链；更新已有绘本无需修改固定地址表。

权限测试：`node scripts/test-book-admin.cjs`。

管理页面顶部的“书架管理”列出所有绘本（包含动画配套书）。按住书名前的 ⠿，拖到另一张绘本卡片上，松开后自动保存摆放顺序。普通书架与动画全集绘本库均按此顺序显示。保存失败会保留原来的顺序。

每张卡片的“删除”按钮会再次确认，确认后从全站目录移除该绘本，保留 Pone 原 PDF。删除和顺序保存在 `public.story_book_shelf`，同样启用管理员专属写入的 RLS；静态目录中的绘本也可删除，刷新后不会重新出现。删除不清除用户已有阅读进度。

交互测试：`node tests/book-shelf-admin.browser.cjs`（Playwright + Edge）。新增环境需先执行 `supabase/migrations/20261102100000_story_book_shelf.sql`。

Little Fox 动画配套绘本通过静态目录的 `seriesIds` 关联动画，显示在动画课程的“全集绘本库”，不再重复出现在独立绘本书架。云端更新同 ID 绘本时会保留这项关联；管理员下拉框仍可找到这些绘本进行更新。对应库支持直接 PDF 和本站阅览器，阅览器返回按钮会回到原动画绘本库。
